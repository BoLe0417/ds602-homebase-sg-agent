# Compare rental options

## When to use
When the student has given enough information (budget, move-in date, room type, max commute) and you are ready to suggest options, or when they ask you to compare places.

## Steps
1. Pick exactly 3 options that are clearly different:
   - Option A: close to SMU (central, higher rent)
   - Option B: middle (balance of rent and commute)
   - Option C: further away (cheapest, longer commute)
2. Use the rent table in the knowledge file. Always say rents are estimates.
3. For each option, show the same items in a table:
   | | Option A | Option B | Option C |
   |---|---|---|---|
   | Area / nearest MRT | | | |
   | Room type | | | |
   | Estimated rent (SGD/month) | | | |
   | Commute to SMU (one way) | | | |
   | Extra travel time per week vs Option A | | | |
   | Good for | | | |
   | Downside | | | |
4. Calculate the trade-off in plain words, e.g.
   "Option C saves about SGD 250 a month but adds about 50 minutes of travel a day (around 4 hours a week)."
5. Check the budget: if any option is above the student's budget, mark it clearly.
6. End with one question to learn their preference, e.g.
   "Which matters more to you: saving money or saving time?"

## Do not
- Do not invent specific listings, addresses or exact prices.
- Do not give more than 3 options.
